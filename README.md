# 🌍 Beyond GDP Dashboard

## Lancer l’application

1. Cloner le projet :

git clone https://github.com/ton-username/ton-repo.git


2. Installer les dépendances :

pip install -r requirements.txt


3. Lancer le dashboard :

streamlit run app.py


---

## Utilisation

- Sélectionner un pays ou plusieurs pays  
- Choisir les indicateurs à analyser  
- Explorer les graphiques interactifs  
- Comparer les performances économiques, sociales et environnementales  

---

## Données

Données issues de la Banque mondiale (World Development Indicators).
